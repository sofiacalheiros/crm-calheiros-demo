# CRM Calheiros — Demo (protótipo)

Protótipo do CRM interno da Calheiros Embalagens, em formato PWA (abre no telemóvel e no computador).

- **Apenas demonstração.** Funciona com **dados fictícios** (`FONTE_DADOS = "local"`). Não está ligado a nenhuma base de dados nem ERP real.
- O código-fonte e o histórico de desenvolvimento estão num repositório **privado** separado.
